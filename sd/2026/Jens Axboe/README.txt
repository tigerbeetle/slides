io_uring - SD '26 slide deck (browser presentation)
=====================================================

Just open  index.html  in any modern web browser (Chrome, Firefox, Safari,
Edge). No internet needed. Copy the WHOLE folder to the USB stick - index.html
plus out.webm (the slide 2.1 video, which autoplays when you reach that slide).

Controls
--------
  Right arrow / Down / Space / PageDown / Enter / click right  -> next slide
  Left arrow / Up / PageUp / Backspace / click left third      -> previous
  Home / End                                                   -> first / last
  f                                                            -> fullscreen on/off
  g                                                            -> show slide number

Tip: press  f  (or F11) for fullscreen before presenting. The deck is 16:9
and scales automatically to fit the screen/projector.

To resume on a given slide, add #N to the URL (e.g. index.html#17).
